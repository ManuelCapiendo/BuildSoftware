# ED2 - *Taskboard*

Submitted by: **Manuel Capiendo**

Z-Number: **Z23746021**

**Taskboard** is a full-stack web app where users can register an account, log in, and manage their own private list of tasks. Each task has a title, an optional due date, and a status (To do, In progress, Done). All data is stored in a PostgreSQL database and each user can only see their own tasks.

Time spent: **X** hours spent in total

## Required Features

The following **required** functionality is completed:

- [ ] User can register a new account with email and password
- [ ] User can log in and log out
- [ ] User can create a task with a title and optional due date
- [ ] User can view all of their tasks in a list
- [ ] User can update a task's title, due date, and status
- [ ] User can delete a task
- [ ] Each user only sees their own tasks (enforced by Row Level Security in the database)
- [ ] App is deployed and accessible at a public URL

The following **optional** features are implemented:

- [ ] Tasks can be filtered by status (All, To do, In progress, Done)

The following **additional** features are implemented:

- [ ] Architecture diagram showing the full data flow from browser to database
